How it works

Paste a GitHub PR, Actions run, branch, or Azure build link to start watching. #123 uses this repo.

Supported link formats
  • GitHub PR https://github.com/owner/repo/pull/123
  • Actions run https://github.com/owner/repo/actions/runs/123
  • Branch https://github.com/owner/repo/tree/main (one-segment name)
  • Azure build https://dev.azure.com/org/project/_build/results?buildId=123 (or org.visualstudio.com)

Other URLs or descriptions ask the agent to set up a custom watch.

Checks run locally without AI. PR and branch watches keep watching across pushes; Actions runs and Azure builds stop after completion.
